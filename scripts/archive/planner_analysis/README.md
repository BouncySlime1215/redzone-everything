# Planner analysis scripts (2026-11-09)

One-off scripts behind the five planner reports in [docs/agents/planner/](../../../docs/agents/planner/). Kept so the
numbers can be re-run. Not part of the app. Run from the repo root; `analysis_tmp/` stands for a scratch folder
holding the planner's working files. The folder names match the planners: queue, mind, product, major, boundary.

Why: the scripts lived only in a temp scratchpad that a reboot can erase (build plan WP-00).
