# Saturday world model (~100M params), plan B data

Owner: lane 1. Serves: North Star "crunch live %" and "dead air %", through the Mind's break and next-event heads.
Status: sizing only. The final numbers are filled in from EXP-103 grades.json and the factory manifest once they land.
License: trained on plan B data, so the model is **personal-use, not for commercial release** (grades.json `license`).

## Shape

| knob | value | why |
|---|---|---|
| d / layers / heads | 768 / 12 / 12 | ≈ 86M non-embedding + embedding ≈ 90-100M with vocab v2 |
| ctx | 2048 tokens | vocab v2 is ~50-100 tokens per play, so 1020 would hold only ~15 plays |
| batch × ctx | 64 × 2048 ≈ 131k tokens per step | |
| lr / warmup / decay | 3e-4, 500 steps, cosine to 10% | standard for this size |
| dropout / wd | 0.1 / 0.1 | the pilot overfit by ~17 epochs; dropout stays on |
| selection | valid loss, early stop | locked set never touched |

## Data (plan B, per league time split as in world_model_pilot.split)

- **Vocab v1 shards** (factory pin 5c5db9e, all sources): NFL nflverse 2001-24, NBA cdn + hoopR, CBB hoopR, NHL api-web,
  MLB Retrosheet. Order of size from the pilot: ~1.0-1.5k tokens per game in v1. Green-only v1 was ~80M tokens.
- **Vocab v2** (tokenizer v2, lane 1, due before Saturday): the same plays plus crew A play-table columns and crew B
  context facts (719k facts in b1). Expect ~8-15x the v1 tokens per game, so ~0.6-1.2B tokens. The ledger counts
  derived and new-information tokens separately.
- **Synthetic** (crew E, EXP-1401): mirror + re-time, train only, before each league's first valid night, at most 3x
  real per league (enforced in world_model_pilot `add_extra`). Run as a separate arm.

## Compute

From the pilot: **2.31 A100-hours per 1B tokens at 100M params** (grades.json `sizing_100m`, re-measured by EXP-103).

| run | tokens seen | A100 h | CU (13/h) |
|---|---:|---:|---:|
| v1 only, 400M × 4 epochs | 1.6B | 3.7 | ~48 |
| v2, ~1B × 2 epochs (main arm) | 2B (≈ Chinchilla for 100M) | 4.6 | ~60 |
| + EXP-1401 aug arm, same steps | 2B | 4.6 | ~60 |

Both arms together come to ~120 CU, which fits Colab Pro+ (~500 CU with a ~100 reserve) after tonight's runs
(EXP-086 ~45, EXP-103 ~17, EXP-022 ~10). The 2048 context costs ~15% more attention FLOPs than the pilot's 1020,
which is inside the table's rounding. Colab sessions cap near 24 h, so the trainer must checkpoint to Drive every 30 min.
