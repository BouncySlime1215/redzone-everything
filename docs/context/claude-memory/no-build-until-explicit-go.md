Don't install software or start building until Nick explicitly says "build" or "go". "Lock in" means "focus and plan carefully", not "start".

**Why:** On the RedZone Everything project (2026-11-02) I read "lock in" as a go-ahead and ran `brew install`; he rejected it and said "I never said build, help with the planning."

**How to apply:** While a plan is being discussed, stay in planning mode. Read-only checks are fine; installs, file creation and builds wait for an explicit build instruction.
