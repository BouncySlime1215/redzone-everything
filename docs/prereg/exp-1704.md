# EXP-1704 pre-registration: Watch Value trained on real human-attention labels

Data Division G (attention). Supersedes the outline row EXP-1702. Committed BEFORE any attention label is joined
to a train night or any model is fit (Nov 5 2026). A change after this commit needs a new EXP id
([grading.md](../grading.md) rule 2). Tag on every dataset and model this row makes: **personal-use, not for
commercial release**.

## Hypothesis (Nick, 9:05 AM Nov 5)

Watch Value should learn from what people actually paid attention to, not only from the win-probability swing.
Per-play engagement labels from public, real data, mixed into #166's swing label, raise **% of oracle** on
NBA first, then NFL. A label we could compute from play-by-play alone (drama math) must not do as well, or the
real data adds nothing.

**North Star line:** % of oracle (`pct_of_oracle`), NBA then NFL, each reported on its own. Secondary,
report-only: Big plays seen live, Crunch live, `wv_rank_agree`. Never judged on watch time.

**Guardrail (plan §5):** the objective stays "worth it". An engagement label is a measure of which moments
people found worth watching, never a target to hold the viewer longer. No dark patterns, no nudges, neutral
wording ("engagement") in public docs.

## The label (fixed now, code: scripts/attention_labels.py)

- For play *i* at wall time *t*, a source's value is the max z of either team over (t + lag, t + lag + width]
  (`WINDOWS`: Bluesky 5 min, edits 15 min, pageviews 60 min, velocity 1 min, volume 2 min; lag 0).
- `aux_i` = within-game rank of that value to [0, 1] (`wv_aux_label.rank01`). Plays the source does not cover
  stay uncovered: their target is left at `wv` (no "nobody cared" from a gap). Coverage is reported per league.
- **Flat games count as uncovered** (added Nov 5 15:50 UTC, before any join or fit; label QA only, no outcome
  read): if a source's values over all of a game's play windows are constant, that game carries no
  information and is left at `wv`, not ranked to a uniform 0.5. Label QA on B's NBA backfill: `edit_rate_live_z`
  has a spike (> 0.5) in 12 of 107 NBA games and 0.2% of 15-min bins, so S1 is expected to be weak for NBA.
- **Candidate target:** `y' = 0.7 * wv + 0.3 * aux` (same mix as EXP-1800; not tuned on any split).

## Arms (same features, LightGBM params, seeds 0/1/2, nights; harness scripts/wv_aux_label.py)

| Arm | Watch Value target |
|---|---|
| **A0 baseline** | `wv` (#166 as is) |
| **A1 candidate** | `y'` with the run's source |
| **A2 placebo** | A1 with `aux` shuffled among the same game's covered plays (seeded) |
| **A3 derived** | `0.7 * wv + 0.3 * drama`, drama = mean of within-game ranks of surprise (realized \|ΔWP\|) and suspense (expected next \|ΔWP\| by WP decile and time-left fifth, fit on TRAIN nights only). Novelty 0 |

Each arm drives the decider through the Watch Value path in the pinned backtest with `--oracle`.

## Nights

- Fit on **train** nights only; valid early-stops (redzone/lab/splits.py). Labels are joined to train nights only.
- **Dev grade:** valid nights, per league. Under 8 valid nights in a league = PENDING for that league.
- **Locked** is read **once** by the integrator under the frozen grader at the next release read.

## Success bar (per source run; NBA read first, then NFL; all must hold)

1. **Lift:** A1 − A0 on % of oracle ≥ **+1.0 pt** in the league, night-cluster bootstrap 95% CI (2000 resamples)
   excludes 0.
2. **Not smoothing:** A1 − A2 CI lower bound > 0.
3. **Real data beats math:** A1 − A3 CI lower bound > 0. If A3 alone clears bar 1 and A1 does not beat it, the
   result is "drama math helps, this source does not".
4. **Rule #1:** `entries_mid_play` = 0 and high-leverage leaves = 0 for A1.
5. **Worth-it line not worse** than A0 (CI includes 0 or favors A1).

**Multiple testing:** S1-S5 form one Holm family, `wv-attention-labels` in docs/families.json (integrator,
declared before any label is joined). Bars 1-3 use Holm-adjusted CIs across the five runs. A source that arrives
later (S6 Twitch) gets its own row and family; it never joins this one after results are in.

Any of 1-5 missed = that source does not ship as a Watch Value label. It stays in the ledger as eval-only.

## Leakage

An engagement label is known only after the moment. It is a training target, never a feature: the harness takes
it as `aux` only, and the features stay `features_for()` from #166 (test writers' rule, EXP-302 leak checks).
