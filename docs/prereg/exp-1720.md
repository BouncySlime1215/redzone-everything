# Pre-registration: GI v3 NBA, closeness-anchored (WV loop cycle 1)

Status: DRAFT, written before any fit. EXP-1720 (crew G 17xx block).
Tag: personal-use, not for commercial release. Locked nights (attention-g/locked_nights.json) are never read.

## Question
Does a closeness-anchored ranker pick the better NBA game of a pair (by Polymarket volume) more often than closest-game?

## Data (all derived, no bulk reads by agents)
- Games + features: attention-g/gi/nba_volume_games.parquet (2024-25: 718 games/158 nights, 2025-26: 647/141, 2026-27: 60/10).
- Label: within-night rank of log1p(volume_usd) (crew D). Preseason excluded.
- Added inputs (pre-game only): crew D pre-game market price -> |p_home - 0.5| where available; crew H pregame_report_history (rivalry, streak, last10); team draw = prior-season mean volume rank per team; opening-night Elo carried from prior season end.
- Early-season shrinkage: standings features blended with prior-season value by w = gp / (gp + 10).

## Arms (fixed now, no others on this split)
- C0 closest-game: -|elo diff| (baseline, as in v1).
- C1 market closeness: -|p_home - 0.5|, fall back to C0 when no price.
- G3a lambdarank by night, init score = z(C0), all features above EXCEPT market price and crew H (crew H NBA pregame history covers only 2026-27: 92 games, so it cannot enter a 2025-26 rolling valid; it enters G3c once H backfills 2024-26) (runs now, before crew D's price lands), 200 trees max, NO early stopping on the grading nights (inner split = first 70% of training nights).
- G3b same as G3a with market price and init score = z(C1); runs once crew D's p_home_pre lands. Graded once.

## Grading
- Metric: PAIR-WEIGHTED within-night pair agreement; ties 0.5; nights with < 2 games dropped.
- Valid: rolling origin over 2025-26 by month (train on all nights before the month, 2024-25 at weight 0.5), pooled over months. 
- Fresh check: 2026-27 nights after Nov 5 once >= 40 nights.
- CI: night bootstrap, 5000 draws, seed 1720.
- Pass: G3 - C0 lower 95% bound > 0 on valid AND point estimate >= +2.0. Report G3 - C1 too.
- One run, seed 1720. A fail is logged and the arm is not tuned on these nights.

## What it would mean
Pass -> GI v3 becomes the NBA slate-rank candidate for a fresh-nights read. Fail -> closeness (C1 if better) stays the NBA rule and the next cycle targets the label (excitement vs volume) instead of features.

## Dev result (G3a, 2025-26 rolling origin, run once, seed 1720)
141 nights, 1427 pairs. G3a 61.81 vs C0 56.27 pair-weighted, +5.54, night-bootstrap 95% CI +2.65..+8.50 -> dev PASS.
Mean-over-nights: 62.62 vs 59.95. Full numbers: docs/prereg/exp-1720-dev-G3a.json.
