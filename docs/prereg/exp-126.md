# EXP-126 pre-registration: STAY/LEAVE pairwise ranker at the measured feed lag (lane 1)

Committed Nov 5 2026 before any EXP-126 data is built. Runs on the eval-data-v3 pin (Fri Nov 6), not on the 9 v1 valid
nights that EXP-1712/1713/1714/125 already used.

- **Why:** regression of per-game value-to-go helps only with a wide window (EXP-1714 at 8 s feed lag) and loses at the
  measured p90 feed lag (EXP-125). The decision is "which game now", so learn the order, not the level.
- **Model:** LambdaRank-style pairwise loss (sklearn-free: a small GBM on pair differences, or LightGBM `lambdarank`
  if available on the runner) over games live at the same 30 s step; target order = realized 300 s reward of each
  game without the your-team term (EXP-1714 head 1). The your-team term enters as in EXP-1714 (100 x flag x crunch
  head). Same features. Watch Value (`watch_value`, crew G) joins as a feature only once EXP-1704 passes.
- **Policy:** `stay_leave.solve_policy` at the measured per-league feed-lag p90, B = 60 s, no band, same floors.
- **Arms:** A0 v1 past mean; B1 (EXP-1714 two heads); R1 ranker.
- **Bar:** pooled % of floored oracle R1 - A0 >= +1.0 pt with CI excluding 0, no league worse than A0 beyond its CI,
  switches/h <= A0 + 10 %, 0 floor leaves, 0 mid-play entries. v3 valid nights, >= 8 per league or PENDING.
- **Locked:** read once by the integrator.
