## What is graded

The **one** model crew G nominates from its dev work (EXP-1704 and the joined attention-label table), chosen on
**valid** nights only. The nomination is written to `docs/prereg/exp-1405-nominee.json` (model id, data hash,
code pack, seed, label sources, train and valid nights, valid grade) **before** the integrator opens a locked night.
A second nominee after a locked read is a new EXP.

## Arms (identical decider, pinned backtest, `--oracle`, both harnesses: honest and `--resync`)

| Arm | Watch Value source |
|---|---|

## Metric

- **Primary:** % of oracle per league (`pct_of_oracle_<lg>` in scripts/northstar.py: worst of big live, crunch
  live, live air). Each league is reported on its own, NBA first, then NFL, then NHL. A pooled number is never the
  verdict.
- **The ceiling is the floored oracle** (EXP-1714): `oracle.solve` with the never-leave-high-leverage floor applied.
  The unfloored oracle is reported beside it.
- **Secondary, report only:** big plays seen and live, crunch live, your-team crunch live, dead air, switches/hour,
  `wv_rank_agree`, and ECE of Watch Value against the realized engagement rank (rule 6). Never watch time.

## Success bar (per league; all must hold for L3 to be called better)

1. **L3 beats the clock score:** L3 − L1 on % of oracle ≥ +1.0 pt, and the night-cluster bootstrap 95% CI
   (2000 resamples, seed 1405) excludes 0.
2. **L3 beats live:** L3 − L0 CI lower bound ≥ 0, and no key line (big live, crunch live, your-team crunch live,
   dead air, plays missed on entry) worse than L0 beyond its CI. This is scripts/release_gate.py
   `league_promotion`'s rule.
3. **Real attention adds something:** L3 − L2 CI lower bound > 0. If L3 clears 1 and 2 but not 3, the verdict is
   "Watch Value helps, the attention labels do not (yet)".
4. **Rule #1, hard:** entries mid-play = 0 and high-leverage leaves = 0 for L3, on both harnesses. One violation
   fails the league, whatever the rest says.
5. **Both harnesses agree in sign** on bars 1 and 2.

**Multiple testing.** Bars 1-3 for one league form a Holm family of three. The family is `wv-v1-locked-<lg>` in
docs/families.json, declared by the integrator before the read.

## Power and PENDING (honest about the locked set)

eval-data-v1 locked nights: **NBA 4, NHL 4, NFL 19**. With 4 nights, a night-cluster CI on a +1 pt lift cannot
exclude 0 unless the effect is very large. So:
- A league with **< 8 locked nights** is reported **PENDING (underpowered)**. The point estimates and CIs are
  still shown, but there is no PASS or FAIL. Today that is NBA and NHL, until eval-data-v3 (Fri Nov 6, adds
  2025-26 NBA) lands. Bar 4 still applies: a Rule #1 violation is a FAIL even when the league is PENDING.
- NFL (19 nights) is graded now.
- Label counts don't change this. Millions of labeled moments make the model better; only more locked **nights**
  make the grade sharper.

## Leakage and hygiene checks (run before the read; any failure = VOID)

- **Time split:** no train or valid night falls on or after the first locked night of its league
  (`splits.league_split`). No locked night appears in the nominee's manifest.
- **Labels never as features:** the nominee's feature list matches #166 `features_for()` (the byte-identical
  test in #317).
- **Context-only label check:** scripts/label_leak_check.py on each attention source the nominee uses (dev nights
  only). Context-only AUC ≥ 0.95 = VOID for that source.
- **Adversarial validation** (rule 5): a classifier that tells train from locked rows on the nominee's features
  must be near chance (AUC ≤ 0.60).
- **No Nick signal:** no feature or label is derived from Nick's viewing or button presses (manifest check).
- **No Teacher labels:** Teacher outputs may be inputs only after EXP-1404 and EXP-1711 pass; they are never labels.
- **Golden nights:** the nightmare-night regression suite (rule 7) must not get worse for L3 vs L0.

## Output

`docs/reports/exp-1405-locked.md` and `grades.json`, with seed, data hash, code pack, nominee id, the locked night

line if a league's Watch Value default changes. Any change ships league-scoped and flag-off until Nick flips it.
