# EXP-1714 pre-registration: STAY/LEAVE v1.1, two heads and a floored ceiling

Lane 1, Nov 5 2026, committed after EXP-1712's valid read and BEFORE any EXP-1714 fit. A new id because
EXP-1712 failed and its rules say a failed row is not re-tuned ([grading.md](../grading.md) rule 2).

## Why (EXP-1712 valid read, 9 nights pooled)

A1 (learned beyond-window value) scored **70.1 % of oracle vs A0's 86.3 %** (Δ -16.2, CI [-46.6, +6.2]); NBA
47 % vs 88 %. 0 high-leverage leaves and 0 mid-play entries on every arm. Diagnosis, from the per-night rows: the
label folds in the your-team crunch weight (x100, an L1 rule), so the regressor's value is dominated by one
rare, huge term; on nights with a WSH game it parks on that game outside crunch and misses big plays elsewhere.
Second finding: the full-hindsight oracle itself leaves a high-leverage game 45 times on those nights, so its
100 % includes moves our floor forbids.

## Change (fixed now)

- **Head 1:** value-to-go over 300 s WITHOUT the your-team term: 3 x big + 1 x crunch - 0.02 x dead step.
- **Head 2:** crunch plays over the next 300 s (same features). Beyond value = head 1 + 100 x your-team flag x
  head 2: the your-team term enters as that game's predicted crunch, not as a free bonus.
- Same features, learner, HP, `max_iter` grid (picked on valid), seeds, rows, buffer as EXP-1712.
- **Ceiling:** % of oracle is reported against BOTH the full-hindsight oracle (as EXP-1712) and the
  **floored** full-hindsight oracle (`oracle.solve` on a leave table with the no-leave floor applied). The
  floored one is the primary 100 %: it is the best any policy under Rule #1's floors could do.
