## Change (all flags off; one change set, sim = live)
- `redzone/decider/whistle.py`: `clock_stopped(events, a, band)`: lane 3's clock-truth rule (dead = <= 10 s after
  foul/timeout/violation/free throw/end of period, a period change, or the clock ran < 0.3 x wall between the events
  around `a`), required for every second in a +- band (3 s, `decider.entry.whistle_band_s`). Needs the next event, so
  only works behind a buffer. Timeline keeps `clock_events` (wall, period, clock, type) for it.
- Live: engine `_flip_lands_whistle` joins `may_cut` for non-user switches: on the scrub path (`_scrub_wanted`), a
  basketball target in `decider.entry.hold_only` flips only when `clock_stopped(timeline, now - delay.mu)`. Off the
  scrub path or another league: unchanged. Gives up after MAX_SAFE_WAIT_S (25 s) like any flip. NHL (also hold_only)
  is NOT covered: no hockey clock rule yet; scrub stays off for NHL.
- Sim: `HiddenStick.recheck_rule = "whistle"` (`--hs-recheck-whistle`): the re-check calls the same `clock_stopped` on
  the plays the app has by then, at the believed screen moment. A re-check past 25 s still waits on (as EXP-604
  preregistered; live drops and re-picks, which the sim can't model): counted as late_over_25s and disclosed.
- 90 s scrub cost. Source: Nick's stick test relayed Nov 7 05:54Z (project chat message
  cmsg_011rPfhndEhhnAPuwfcdBQK8XnmagY71RBnd3PAhTVFXvg): asked 90, 6 presses took 37.6 s and landed 130.8 s behind
  (overshoot = overlay time; the SEEK_TO thread fixes the press count). Later #391 runs (relayed by the integrator,
  06:23Z) took 28.0 / 17.5 / 17.8 s. Pre-committed: the verdict arm uses the WORST measured, 37.6 s
  (`scrub_90_measured`: 37.6 s keys + one 7.5 s read, landing at B); the report arm's `scrub_measured` (15 s + 7.5 s)
  brackets the faster #391 runs. No value is picked after seeing results.
