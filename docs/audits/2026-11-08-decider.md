## S1

### D-01 CONFLICT (S1): the default entry path joins live mid-play in five ways, and only NBA/NHL/NFL have their overrides

Rule #1 says 0 mid-play joins, hard (CLAUDE.md; decisions 2026-11-04 3:15 PM "never JOIN mid-play ... fails bar (a) outright").
`Decider._time_entry` (decider.py:1314-1387) has these exits that enter live with no dead-ball proof:

1. `decider.py:1360` `return d   # no clean landing in reach: crunch time (and rewind-only leagues) don't wait`, taken when
   `x.scored.crunch_now and self._crunch_entry_mode(x) == "rewind"`. Default config: `decider.entry.crunch_now: rewind`
   (default_config.yaml:279, comment says "(land on a whistle if a rewind fits)" and the code comment at decider.py:1290 says "else go now").
2. `decider.py:1375-1378` the whistle-wait cap: `if not pos and cap is not None and now - w[1] >= float(cap) and (d.kind == "ended" or ... late): return d`.
   Default `max_wait_s: {nba: 180}` (default_config.yaml:280). `cap` is read with `self._lg(x)` = the FULL league, so CBB and WCBB
   (base "nba") inherit the 180 s cap even though NBA's own override clears it (`decider.entry.max_wait_s: {}`).
3. `decider.py:1362` `no_wait_leagues` (key not in default_config; empty by default so latent).
4. `cuts.py:553-583` `plan_entry`: an "unknown" landing ("the data can't call it") returns `EntryPlan(True ...)` unless the league is in
   `decider.entry.unknown_wait_leagues`, which defaults to `[]` (default_config.yaml:274, "Off until its gate passes").
5. `decider.py:1338` `if plan is None: return d`. `_entry_plan` returns None when the game has no timeline or `not tl.dead.marks`
   (decider.py:1190). A game whose feed has no dead marks yet (first poll, an ESPN gap, a league with thin play-by-play) is entered with no timing.

`league_overrides` (default_config.yaml:913-966) exist only for nba, nhl, nfl. The comment says "CBB, CFB, WCBB and MLB stay on live
behavior until graded". So CFB, CBB (Nick's league), WCBB and MLB run exits 1, 2 (CBB/WCBB), 4 and 5 by default.
Even NFL's override (`crunch_now: wait`, `max_wait_s: {}`) leaves exits 4 and 5.

Why it matters: Rule #1 is the one hard rule. The per-league promotion rule (decisions 2026-11-04, "A candidate change may go live in
one league when, in THAT league, it has 0 mid-play entries") covers promoting an improvement, it does not make a live mid-play join acceptable for
the leagues that are not graded. CFB and CBB are ranked 2 and 4 in Nick's league order.

Fix: make exits 1 to 5 default to "wait" (or rewind-only) for every league. CBB/WCBB/CFB should get the NBA/NFL override set
(the override keys are keyed by full league, so copy them, or have `_lc` fall back to `league.base` when the full league has no block).
Keep a live fallback only behind an explicit `decider.entry.allow_live_fallback: true`.
Test: a decider test per league (cfb, cbb, wcbb, mlb) where the only landing is mid-play for longer than 180 s and `crunch_now` is true; assert the decision stays "stay"
and `entries_mid_play == 0`. Extend `scripts/ci_scorecard.py` to print CFB/CBB rows.

## S2

### D-02 GAP (S2): MLB has no entry timing at all, and no first-pick timing in any league but NHL

`_cut_timed` (decider.py:1241) is `lg in (decider.entry.leagues or ["nfl"])` on `league.base`, and `_entry_only` (1251) is `hold_only: [nhl, nba]`.
MLB is in neither, and `rewind_only` is `[]`. So every MLB switch (including an MLB crunch pick, `row("run_up","mlb")`) skips `_time_entry` completely
(decider.py:1318 `if not self._cut_timed(...) and not self._entry_only(...): return d`). MLB is last in the league order but it still
joins mid-pitch.
Also `decider.entry.start_timed: false` (default_config.yaml:303; only the NHL override sets true): `_entry_only` returns False for `d.kind == "start"`
(decider.py:1259), and `_safe` exempts "start" (playbooks.py `d.kind in ("user","start")`). The "first pick of the night" comment hides that `kind="start"` is also what the
decider emits after every restart or `forget_screen` (decider.py:1873, `kind = "start" if self.current is None else "ended"`), so it recurs mid-night.
Fix: add mlb to `decider.entry.leagues` (and give it a landing rule: between batters / half-inning), turn `start_timed` on globally.
Test: MLB switch with a live pitch window on arrival must stay; `kind="start"` after `forget_screen` must wait for a dead ball.

### D-03 CONFLICT (S2): jump-mode crunch hold keeps a neutral crunch game on screen through every commercial break

`_jump_hold` (decider.py:2507-2511) returns `"crunch"` for any `s.crunch or s.crunch_now or lock in CRUNCH_LOCKS`, and `_jump` returns None (no jump) for it.
The normal decider is deliberately narrower: `_crunch_holds` (decider.py:~2401) holds a neutral crunch game only for `hold_neutral_breaks: [two_minute_warning]`
because "every stoppage held is commercials on screen". The 2026-11-08 pass bar is "0 commercial seconds on screen" in every 10-minute window, "applies to every sport".
A final-3:00 NBA or final-2:00 NFL game (3 timeouts each, a review, the 2:00 warning, plus the crunch flag running from 3:00/7 in NBA) holds the screen through
2 to 4 minutes of ads.
Fix: in `_jump_hold`, hold a crunch game only while it is live, or when `personal >= hold_personal`; at a break let the rotation jump (the crunch game stays reachable and is re-picked by value).
Test: jump-mode scene with the screen game crunch and `is_break` true, standby ready and landing dead; expect a jump (today: `jump_holds["crunch"]`).

### D-04 CONFLICT (S2): jump rotation does not honor "your team first" or league order outside crunch

`_jump_hold` ignores `s.personal` / `mine` / `mine_late` / `late and close`; `decider.crunch.mine_first` and `_mine_late` (decider.py:3558-3580) are only consulted on the
normal path, and `_jump_owns` (decider.py:2905) turns every optional normal-path stay into a rotation decision. So a WSH or UNC game in the 4th quarter,
3 points, 8 minutes left (not crunch) is left after `max_plays: 2`.
`_jump_value` (decider.py:2650-2656) adds `snap_bonus 15 + big_bonus 20 + rotate_per_min 6 x up to 5 min = 30`: up to 65 points on a 0-100 score. League weights
differ by 5 percent (default_config.yaml:124, nfl 1.15, cfb 1.10, nba 1.05, cbb 1.0, nhl 0.95, mlb 0.9) and the personal boost is added to the same `scored.score`,
so the fairness and snap bonuses can outrank "your team" and league order.
Fix: `_jump_hold` should hold `self._mine_late(s)` (and `s.late and not garbage and personal >= hold_personal`); in `_jump_value` scale the bonuses down or add a league / personal prior (as `_crunch_value` does).
Test: WSH Q4 8:00, 3 pts, ready standby with a snap-next neutral NFL game; expect a hold.

### D-05 ERROR (S2): `jump_may_leave` treats a 20 s-stale timeline as "nothing on screen", but the buffered screen runs 75-110 s behind the data

decider.py:2582-2586:
```python
if gid not in cands and self.buffered_on():
    tl = self.timelines.get(gid)
    if tl is None or tl.fresh_at is None or now - tl.fresh_at > STALE_DATA_S:
        return True
```
`STALE_DATA_S` is "older than this, 'no play in the data' no longer means 'no play on screen'" (screen.py:51). With both sticks scrubbed 75 s behind plus the 35 s edge,
a game that dropped out of `cands` (engine.py:1608 skips every game whose `phase != LIVE`: a final, a delay, a suspended game, a parse glitch) still has ~110 s of play on the screen after the data stops.
A feed that has been dark 21 s does not make the picture dead. The normal path guards this with `_gone_hold` (decider.py:~2260: final_at + mu + 2 sigma, `GONE_MAX_HOLD_S`), and `_bj_screen_gone`
(decider.py:2759) has no equivalent; it also takes precedence over the normal "ended" switch (`_own`, `screen_gone`).
The decision-side free cut then relies on the flip-time `jump_may_leave` alone, which for a stale timeline always says yes.
Impact: a mid-play leave (possibly at a high-leverage moment, e.g. a final that just posted with the last play still airing) on the buffered path.
Fix: compare staleness to the screen's delay: `now - tl.fresh_at > STALE_DATA_S + d.mu + 2 sigma`, and apply `_gone_hold` inside `_bj_screen_gone`.
Test: `test_buffered_jump.py::test_screen_game_gone_from_the_feed_is_a_free_cut` only covers a gone game with NO timeline. Add one with a timeline, last play 25 s old, mu 110 s: expect no cut.

### D-07 CONFLICT (S2): "never Peacock" is enforced in one place that is off by default

The decider's `watchable` is `x.target and not x.stale and not muted` (decider.py:~1810). The only app ban is `noggin.priority.banned_apps: [peacock]` (default_config.yaml:859),

### D-08 CONFLICT (S2): the thin-margin entry passes knowingly land below the Rule #1 margin

`plan_entry` (cuts.py:557-577) accepts a landing at `relaxed` (8 s) or `urgent` (`ENTRY_URGENT_S = 2.0`, decider.py:123) doubt when the full `2 sigma + 2 s` margin has no landing.
`_time_entry` sets `urgent = d.kind == "crunch" or x.scored.crunch or _sticky_home(entry=True)` (decider.py:1327), i.e. exactly the moments that matter most. A delay with sigma 6 s gets a 2 s margin for a crunch entry:
a mid-play entry is possible by construction. The only guard is SAFE-02, and `playbooks.safe.enabled` defaults to False (playbooks.py:`enabled()`).
Decisions only show these thin passes graded on dev/locked for NBA/NHL/NFL.
Fix: tie `urgent` to the same per-league promotion as the others (off for CFB/CBB/MLB), or turn `playbooks.safe.enabled` on.
Test: a scorecard row with `entries_mid_play` split by the `(urgent)` and `(centred)` tags.

## What's solid

- Owner logic (`Decider._own`, decider.py:2864-2902) is one function with a clean priority order (safe, user, replay, jump_off, just_arrived, screen_gone, hard, not in rotation, rotation). `decide()` calls it once per tick, `_jump` and `_jump_owns` take the result, and `machines/decider.py` documents all eight states. No path lets the rotation and the normal decider both switch in one tick.
- Every "hard" switch (crunch, ended, chase, drive, start) still passes `_time_entry` (except `user`, `resume`, `skip` which are exempt by design); `_crunch_floor` and `_safe` run after the rotation's switch too.
- The jump leave and landing both use dead windows with 2-sigma margins (`dead_through`, `lands`, `jump_lands_dead`) and the flip-time re-check (`jump_may_leave`); the low-leverage mid-play leave is refused when buffered is on (`_jump_gate`, decider.py:2535-2541).
- League order in the crunch pick is read from one source (`models.LEAGUE_ORDER` through `core.league_rank`); `crunch.py` is one small table with a tested `inside()`; college halves map through `pro_period`; `scoring.engine.high_leverage` covers CFB/CBB/MLB through `.base` (so the known CLOSE_LATE gap is lab-only).
- Your-team-first is implemented in four places on the normal path (`_crunch_go` personal lead, `_mine_first`, `_mine_late` stay, replay `yours=`) and `_leavable` refuses a mid-play leave of your team's game whatever its score.
- `_dwell` is off and only ever turns a switch into a stay; no dwell/hold rule on the normal path fights another one (the fights are in D-03 and D-04, between the rotation and the normal rules).
